# Script_Tool - 嵌入式整机测试工具集

本项目用于四轮电动代步车及电动轮椅的自动化测试、固件升级和白盒测试，涵盖从 SMT 板级测试到整机总装测试的完整流程。

**主要模块**

* L5系列SMT&组装升级测试工具：负责 L5 系列主控板及整机组装阶段的固件升级与功能测试。
* R3_MCB白盒测试：负责 R3 系列主控制器（MCB）的接口、通信及功能白盒测试。
* R3系列总装测试工具：负责 R3 系列整机下线阶段的综合功能校验。
* Tool & libs：封装常用的串口/CAN通信协议、底层工具函数与依赖库。

**环境要求与安装**

1. Python 环境：Python 3.11.9
2. 安装依赖依赖库：
   pip install -r requirements.txt

**使用说明**

* 运行指定模块的入口脚本启动测试工具。
* 可直接运行 `git_sync.bat` 完成本地与远程代码的同步。
